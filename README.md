# digital-forensic-investigation
Digital forensic investigation of a simulated disk image using AccessData FTK, evidence correlation and MD5 integrity verification.

Module: Digital Forensics
Institution: Technological University Dublin
Tools: AccessData FTK, FTK Imager, WinMD5Free

# Project Overview
This academic investigation involved examining a simulated forensic disk image to identify and analyse digital evidence relating to suspected financial misconduct.
The objective was to recover relevant artefacts, establish connections between different sources of evidence and document investigative findings.

# Investigation Process
Examined a forensic disk image using AccessData FTK.
Analysed recovered emails, financial documents, browser activity and travel-related records.
Correlated digital artefacts to investigate possible financial misconduct.
Recovered financial information from a ZIP archive when direct export attempts were unsuccessful.
Verified forensic image integrity by comparing its MD5 checksum against a supplied reference value.

# Findings and Analysis
The investigation identified digital artefacts relevant to the simulated case, including communications and financial records.
Evidence from multiple sources was examined together to develop investigative leads. Findings were documented with appropriate consideration of uncertainty, distinguishing potentially suspicious activity from verified conclusions.
